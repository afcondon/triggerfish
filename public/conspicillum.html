Presets

Mash these. The ones marked prog advance a chord per cycle, so the corpus is re-ranked under your hands while it plays.

Source

What the grains are cut from. Whole corpus is the Borderlands move — every grain re-picks, so one cloud spans many samples.

Grain

Where in the source each grain is taken, and how long it is. spray randomises the position per grain — 0 is a fixed read head.

A grain's window must be as long in the source as sustain is in time, or it is transposed. The engine handles that. Opens near 0 because a chord hit is a short attack and a very long tail — a slider over eleven unseen seconds is a guess, and the fix is a waveform behind it, not a better default.

Onsets

A cloud is a pattern: these are cycle positions, and each one is a grain with an ordinal. Density is free to ~12,800/sec.

Voice

The base values every grain gets, before rules. accelerate is a ratio: end speed = speed × (1 + accelerate).

Rules — the part no granulator has

A grain is an event, so it has an ordinal, so you can count it. Every 3 0 costs one Int and is unavailable to Arbhar, Morphagene and Borderlands alike: there, a grain has no identity to count.

op length scales that grain's sustain; speed −1 is the reversed grain. chance re-rolls per grain from the cycle seed, so a cycle is reproducible and cycle 400 is directly addressable. Ops from shape down are the effects, and they are absolute: a rule engages an effect on the grains it selects.

Effects — per GRAIN

These are SuperDirt's per-event modules, and every one is addressable by a rule above. Zero is off: the encoder drops it and no synth is made, so a dry cloud costs what it always did. pshift is the one to try first — it transposes without changing the grain's length, which a tape-speed read head structurally cannot do.
The resonator's tail stops when the grain does, because SuperDirt frees the event group after sustain. So ring it by opening the gate wide and letting gr env make the grain short: a long sustain with gr tilt near 0 is a percussive burst of sample and then the resonator singing out the window — which is how a struck instrument behaves.

rsn follow tunes the resonator from the chord the query is asking for, so a progression re-tunes it on the same boundary it re-ranks the corpus. chord tones writes one rule per tone, so consecutive grains pluck up the chord. The rsn pitch slider then chooses the register — its octave is kept, its pitch class replaced.
It retunes whichever resonator is engaged, the chain's included, and it never switches one on: a preset that rings the chain and leaves the per-grain one off keeps it off.

Chain — per ORBIT

One reverb, one delay, one leslie for the whole cloud — not per grain, and so not rule-addressable. These are sent with every grain because SuperDirt's global effects only ever resume: a reverb once told room keeps going until something tells it room 0. rsn send is the resonator that rings — the per-grain one above has its tail cut when its grain ends, because SuperDirt frees the whole event group after sustain. Here the cloud is the exciter and one body does the singing.
